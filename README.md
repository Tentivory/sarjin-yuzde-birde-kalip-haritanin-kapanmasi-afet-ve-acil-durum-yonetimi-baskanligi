# sarjin-yuzde-birde-kalip-haritanin-kapanmasi-afet-ve-acil-durum-yonetimi-baskanligi
Telefon şarjının yüzde birde kalıp navigasyonun kapanmasını resmi afet, milli batarya egemenliği ihlali ve acil durum sapması sayan; kabloyu kurtarma ekibi, yüzde biri kırmızı alarm, 'az kalsın prize takardım' cümlesini afet bildirimi ilan eden Başkanlık. Gerçekten çalışır. Yüzde birler artık sirendir.
